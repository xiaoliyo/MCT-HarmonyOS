# MCT-HarmonyOS 使用文档

MIFARE Classic Tool（MCT）HarmonyOS 移植版使用说明。

> 本应用面向至少对 MIFARE Classic 技术有基本了解的用户。几乎所有数据的
> 输入和输出均为十六进制。向某些块写入错误的数据可能会对标签造成
> 无法修复的损坏。

## 首次启动

首次启动时会弹出免责声明对话框，请阅读并点击"确定"。随后应用会检测
设备 NFC 状态：

- **NFC 未启用**：可前往系统设置开启，或选择"离线"模式
- **设备不支持 NFC**：可选择"离线"模式（仍可编辑/分析转储和密钥文件）
- **NFC 正常**：贴近 MIFARE Classic 标签即可使用全部功能

## 读标签

1. 进入"读标签"页，勾选一个或多个密钥文件（如 `std.keys`）。
2. 点击"映射密钥到扇区并读取"，保持手机贴近标签。
3. 应用会逐一尝试密钥文件中的每把密钥（Key A / Key B），映射到各扇区。
   进度条下方会实时显示当前扇区与正在尝试的密钥序号。
4. 映射完成后自动读取标签内容，按扇区展示，可保存为 `.mct` 转储文件。

**密钥映射可能较慢**：每个扇区最坏需要尝试（密钥数 × 2）次认证。
`extended-std.keys` 含 7000+ 把密钥，单扇区可能需要数分钟。建议：

- 日常使用勾选 `std.keys` 即可
- 可在映射页点击"更改"缩小映射范围（如 0 - 15）

## 写标签

进入"写标签"页后，选择写入方式：

- **写块**：选择扇区/块，输入十六进制数据写入
- **写值块**：写入 MIFARE 值块（带格式校验）
- **从转储写**：选择 `.mct` 转储文件，整卡或按扇区写回
- **克隆 UID**（工具内）：对支持 UID 写入的特殊卡使用

写入同样需要密钥：应用会先运行密钥映射（同读标签）。
**写入前请备份数据**，错误数据可能永久损坏标签。

## 编辑 / 分析转储文件

转储编辑器打开 `.mct` 文件（每块一行十六进制）：

- 点击任意块可编辑内容
- 选择扇区/块后可用内嵌工具：
  - **AC 解码器**：解析访问条件字节
  - **值块 → 整数**：解码值块
  - **HEX → ASCII**：按文本查看
  - **diff**：与另一转储比较差异

编辑后点左上角软盘图标保存，或用 ⋮ 菜单导出/转换格式。

## 密钥文件

密钥文件为 `.keys` 纯文本，每行一把 12 位十六进制密钥（6 字节）：

```
FFFFFFFFFFFF
A0A1A2A3A4A5
D3F7D3F7D3F7
```

内置密钥文件：

| 文件 | 说明 |
| --- | --- |
| `std.keys` | 常见默认密钥（几十把，映射快） |
| `extended-std.keys` | 扩展密钥字典（7000+ 把，映射慢） |
| `hotel-std.keys` | 酒店卡常见密钥 |

可在"编辑 / 新建密钥文件"中增删改查，或从外部导入。

## 常见问题

**Q：映射一直停在进度 0，是不是卡死了？**
不是。进度条每个扇区更新一次；使用大密钥文件（如
`extended-std.keys`）时单扇区需要数分钟。观察进度条下方的
"扇区 N：正在尝试第 X/Y 把密钥"确认正在进行。

**Q：提示"未找到有效密钥"？**
所选密钥文件中没有该标签的密钥。换其他密钥文件，或获取该卡系统
的实际密钥后新建密钥文件。MCT 不支持破解密钥。

**Q：模拟器上能测试吗？**
模拟器没有 NFC 硬件。可在模拟器上使用离线模式编辑/分析文件，
读卡功能需真机 + 实体标签。

**Q：读出的数据全是 0 或报错？**
常见原因：密钥错误（读到错误数据）、标签不是 MIFARE Classic、
手机移动导致连接中断。保持手机稳定贴住标签重试。

**Q：支持 MIFARE Ultralight / NTAG 吗？**
不支持。本应用仅支持 MIFARE Classic（S50 1K / S70 4K / Mini）。

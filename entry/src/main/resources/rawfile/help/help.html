1. 一般信息

此工具提供了多种与 MIFARE Classic RFID 标签（且仅与 MIFARE Classic）交互的功能。 它面向至少对 MIFARE Classic 技术有基本了解的用户。 您还需要理解十六进制数字系统，因为所有数据的输入和输出均为十六进制。

一些重要事项如下：
  • 此工具提供的功能非常基础。这里没有那些花哨的功能，例如通过漂亮的 图形界面把 URL 保存到 RFID 标签上。如果您想在标签上保存内容， 必须输入原始的十六进制数据。
  • 此应用无法破解任何 MIFARE Classic 密钥。如果您想读取/写入 RFID 标签，首先需要该标签的 密钥。更多信息请阅读 快速入门一章。
  • 本应用不会有“暴力破解”攻击功能。 由于协议本身的限制，这种攻击方式实在太慢。
  • 此应用在某些设备上无法使用，因为这些设备的硬件（NFC 控制器）不支持 MIFARE Classic （了解更多）。 您可以在 MCT 的 GitHub 页面上找到不兼容设备列表。
有关 MIFARE Classic 的更多信息，请查阅 维基百科、 进行一些 Google 搜索，或阅读 NXP 的 MIFARE Classic (1k) “数据手册”（PDF）。

本应用是遵循 GPLv3 许可证的自由软件。源代码可在 GitHub 上获取。

1.2 数据存储

此应用将数据存储在应用专用的内部存储中。像从标签读出的已保存转储这类文件， 无法被任何其他应用或通过电脑（USB）访问。如果您想在其他地方使用它们， 可以使用分享按钮或 MCT 的 导入/导出工具。

注意！卸载此应用将永久删除所有文件（转储/密钥）。

从 4.0.0 之前的版本升级： 如果您是从 4.0.0 之前的版本升级的，可能会发现所有转储和 密钥文件都不见了。事实并非如此。从 4.0.0 版本开始，MCT 的 文件存储模型发生了变化。您只需使用 导入/导出工具即可找回您的文件。旧文件存储在 外部存储（SD 卡）上一个名为 MifareClassicTool 的文件夹中。转储文件的 格式为 .mct，密钥文件的格式为 .keys。可以一次 导入多个文件。
  • 转储文件：/sdcard/MifareClassicTool/dump-files/（导入为 .mct）
  • 密钥文件：/sdcard/MifareClassicTool/key-files/（导入为 .keys）
MCT 的普通版本和 捐赠版 无法共享同一存储。因此每个版本都有各自的转储和密钥文件。

2. 快速入门

首先，您需要想要读取的标签的密钥。 由于 MIFARE Classic 存在一些弱点，您可以使用 Proxmark3 等工具， 或普通 RFID 读卡器配合一些特殊软件 （mfcuk、 mfoc） 来获取标签的所有密钥（A 和 B）。

本应用自带名为 std.keys、extended-std.keys 和 hotel-std.keys 的标准密钥文件，其中 包含众所周知的密钥以及通过简单 Google 搜索得到的一些标准密钥。 您可以在主菜单中使用“读取标签”尝试用这些密钥文件读取标签。 对这些密钥文件所做的更改将会丢失。请为您的密钥创建您自己的密钥文件。

一旦您知道了某些密钥，就可以把它们放进一个简单的文本 文件中（每行一个密钥）。您可以在电脑上完成此操作，然后使用 MCT 的 导入/导出工具导入该文件； 也可以通过主菜单中的“编辑或添加密钥文件”创建新的密钥文件。 密钥文件配置完成后，您就可以在主菜单中使用“读取标签”读取标签了。

密钥文件概念的优点：
  • 您不必操心哪个密钥对应哪个扇区。
    应用会尝试用密钥文件中的所有密钥向所有扇区进行认证 （类似字典攻击）。
  • 您不必知道所有密钥。
    如果在密钥文件（字典）中找不到某个扇区的密钥 A 或密钥 B，应用将跳过该扇区不读。
这种基于字典攻击的映射过程 （密钥 <-> 扇区）让您可以用已知的密钥 尽可能多地读取数据！

3. 读取标签

从技术上讲，读取 RFID 标签分两步进行：
  • 选择密钥文件
    在主菜单中按“读取标签”。然后选择（可能）包含该标签 密钥的密钥文件。您还可以指定要读取的扇区范围。 使用右下角的按钮启动映射过程。
    但是：对于较大的密钥文件，这可能需要相当长的时间！
  • 读取标签
    在基于字典攻击将密钥映射到扇区之后， 应用会立即开始读取标签。结果将显示在一个 简单的编辑器中（参见 编辑标签转储文件一章。）

4. 写入标签

如果您想向 MIFARE Classic 标签写入数据，理解自己在做什么非常重要。 向某些块写入错误的数据可能导致标签不可修复的损坏。

4.1 写入块

首先，您必须指定要写入哪个块。 典型的（MIFARE Classic 1k）范围是：扇区 0-15，块 0-3。 第二步是输入要写入的数据。数据为十六进制格式， 长度为 16 字节（32 个字符）。 按下按钮后，最后一步是选择（可能）包含该 扇区/块写入权限密钥的密钥文件。

4.2 写入转储（克隆）

使用此方法，您可以将一个转储（或其中的某些扇区）写入标签。 如果您想克隆标签，必须先读取并转储 原始标签。第二步是在另一个标签（您知道其密钥）上恢复转储的数据。 您需要所有要写入扇区的具备写入权限的密钥。
选择转储、扇区和密钥文件后，应用会为您检查一切！ 如果存在“块为只读”、“不知道具备写入权限的密钥”等问题， 写入前您会收到一份报告。

选项：
  • 使用静态（自定义）访问条件
    启用此选项后，转储中的所有访问条件 都将被替换为您所选的访问条件。
    当转储中包含会永久固定在标签上的访问条件时， 此选项很有用。如果读卡器不检查访问条件， 您可以轻松使用自定义访问条件使标签可以重复使用。
  • 写入制造商块
    原版 MIFARE Classic 标签第一个扇区的第一个块 是只读的，即不可写入。但也存在特殊的 MIFARE Classic 标签（即第二代/gen2 魔术标签），支持 通过简单的写入命令写入制造商块。本应用 能够写入此类标签，因此可以创建完全正确的克隆。
    不过，某些特殊标签需要特殊的命令序列才能 进入可写入制造商块的状态。这些标签无法使用。
    另外，请确保 BCC 值（参见 BCC 计算器）、SAK 和 ATQA 值 正确。如果您只是想克隆 UID，请使用 克隆 UID 工具。

4.3 恢复出厂格式

此功能会尝试将标签恢复为出厂/交付状态。在此状态下， 所有数据块的字节均为 0x00，扇区块尾包含 作为密钥 A/B 的 0xFFFFFFFFFFFF 以及作为访问条件的 0xFF078000。

4.4 值块的递增/递减

使用此方法，您可以对值块进行递增或递减，然后进行转存。 如果递增或递减失败，原因是以下之一：
  • 所选的目标块不是值块。
  • 访问条件不允许对该值块进行递增或递减。
  • 提供的值不正确。当您试图将值块递增到超过上限 （2,147,483,647），或试图将其递减到低于下限 （-2,147,483,648）时，就会出现这种情况。
如果递增或递减由于事务被中断而不完整而失败，值块可能变得无法使用。

如果您不知道什么是 MIFARE Classic 值块，应阅读 MIFARE Classic (1k) 数据手册（PDF）的第 8.6.2.1 章。

4.4 值块的转存与恢复

值块可以被配置为仅允许递减。但是，递减权限 也允许执行转存和恢复操作。结合另一个可写块 （中转块），这可以用来绕过仅递减的限制， 从而将值块增加到任意值。

5. 编辑标签转储文件

标签编辑器是一个带高亮显示的简单十六进制编辑器。 可以通过两种方式访问此编辑器：
  • 读取标签
    读取标签后，结果会显示在此 编辑器中（参见读取标签一章。）
  • 打开已保存的标签
    您可以通过主菜单中的“编辑标签转储”来 编辑已保存的转储。
您可以按保存工具栏按钮（或菜单项）将转储保存到文件中。

5.1 分享转储

在转储编辑器中，您可以分享转储（通过工具栏或菜单项）。 您可以在愿意处理该转储文件的应用中进行选择。 请注意，某些应用无法处理转储。
已知可与 MCT 配合使用的应用：Gmail、蓝牙等。

5.2 以 ASCII 显示数据

在转储编辑器中，您可以将数据以 7 位 US-ASCII 显示（通过菜单）。 不可打印的字符将被替换为点（“.”）。 每个扇区的最后一个块，即扇区块尾，不会被 转换为 ASCII。

5.3 显示访问条件

在转储编辑器中，您可以将 MIFARE Classic 访问 条件以表格形式显示（通过菜单）。如果您不知道它们是什么， 可以阅读 MIFARE Classic (1k) 数据手册（PDF）的第 8.6.3 和 8.7 章（及子章节）。

5.4 以整数显示值块

在转储编辑器中，您可以将格式化为 MIFARE Classic 值块的块解码为整数格式（通过菜单）。 有关值块的更多信息，请阅读 MIFARE Classic (1k) 数据手册（PDF）的第 8.6.2.1 章。

5.5 显示制造日期

在转储编辑器中，您可以解码制造日期（通过菜单）。

制造商块（扇区 0，块 0）的最后 2 个字节 表示制造日期。它们应为二进制 编码的十进制格式（BCD，仅数字，无字母）。第一个字节 表示制造周，必须在 1 到 53 之间。 第二个字节表示制造年份，必须在 0 到 当前年份之间（例如 12 表示 2012 年）。

这并不是标准。有些制造商并不遵循这一规则。 因此 MCT 可能无法显示制造日期，或显示错误的日期。

5.6 写入转储

您可以直接从转储编辑器写入转储。关于写入转储， 参见写入转储（克隆）

5.7 比较转储

您可以直接从转储编辑器将当前转储与另一个转储进行比较。 关于比较转储，参见 差异对比工具（比较转储）

5.8 保存密钥

您可以将当前查看的标签的密钥保存到密钥文件中。 这可用于加快相应标签的映射过程，因为新的密钥文件中将只包含有效的密钥。

6. 编辑或添加密钥文件

创建密钥文件有两种方式：
  • 本应用
    您可以通过主菜单中的 “编辑/添加密钥文件”创建新的密钥文件。
  • 在电脑上
    您可以在电脑上创建一个简单的文本文件，然后 使用 MCT 的导入/导出工具导入它。
密钥文件是简单的文本文件，每行包含一个 MIFARE Classic 密钥（十六进制，6 字节，12 个字符）。 以 # 开头的行以及空行 会被忽略。

您可以随时通过主菜单中的“编辑/添加密钥文件” 来编辑密钥文件。

由于密钥文件在字典攻击中的作用类似于字典， 因此只需输入互不相同的密钥即可（即使某个密钥 被多个扇区使用）。您可以在密钥编辑器中（通过菜单）去除 密钥文件中的重复项。密钥文件也可以像转储文件一样 分享（参见分享转储一章）。

其他优点请参见 快速入门一章的 “密钥文件概念的优点”部分。

7. 工具

本节提供了一些处理 MIFARE Classic 的常用工具。

7.1 显示标签信息

在此视图中，您可以看到 RFID 标签的一些常规信息 （如 UID、ATQA、SAK、标签容量等）。

如果您的设备不支持 MIFARE Classic，这就是您在此应用中 唯一能做的事。:(

标签类型与制造商识别：
识别机制基于 此网站。 如果您想深入了解 MIFARE 标签识别，请阅读 NXP MIFARE 类型识别流程（PDF）。PCSC 项目还提供了另一个 基于 ATS（ATR）识别的 有用文件。

由于以下几种原因，MCT 判定的标签类型和制造商可能是错误的：
  • 标签具有自定义的 ATS
  • 读卡器磁场范围内有多个标签

7.2 值块解码/编码器

此工具能够将 MIFARE Classic 值块解码为整数， 反之亦然（将整数编码为 MIFARE Classic 值块）。 如果您不知道什么是 MIFARE Classic 值块，应阅读 MIFARE Classic (1k) 数据手册（PDF）的第 8.6.2.1 章。

在大多数情况下，值块的“Addr”为 00（十六进制）， 因为它并未被使用。不过，按照 NXP 的说法，它
“可以用来保存块的存储地址，以实现功能强大的 备份管理。”。

7.3 访问条件解码/编码器

此工具能够将 MIFARE Classic 访问条件解码为 更易读的格式，反之亦然（编码为 MIFARE Classic 访问条件）。 如果您不知道什么是 MIFARE Classic 访问条件，应阅读 MIFARE Classic (1k) 数据手册（PDF）的第 8.7 章。

7.4 差异对比工具（比较转储）

此工具能够为您显示两个转储之间的差异。 只需选择您想要比较的转储，该工具就会高亮显示 两个转储彼此不同的所有部分。

7.5 BCC 计算器

此工具可以计算位计数校验（BCC）值。对于 4 字节 UID 的 MIFARE Classic 标签，BCC 必须是 第一个块（制造商块）的第 5 个字节。

有关计算 BCC 以及它在防冲突阶段 如何使用的更多信息，请参阅 NXP 的 AN10927。

7.6 克隆 UID

此工具可帮助您轻松克隆 UID。只需触碰 原始标签以读取其 UID，按下按钮，然后将 兼容的标签（“第二代魔术标签”）放到读卡器磁场范围内。 关于兼容的标签，请参阅 写入转储（克隆）一章的 “写入制造商块”部分。

7.7 导入/导出/转换文件

此工具可以导入和导出不同文件类型的转储和密钥文件。 支持 .mct（MIFARE Classic Tool）、.keys（MIFARE Classic Tool）、 .bin/.mfd/.dump（Proxmark、libnfc、mfoc 等）、.eml（Proxmark 模拟器）和 .json（Proxmark、Chameleon Mini GUI）。如果要将转储文件从例如 .bin 转换为 .json，只需先导入再导出即可。

可以一次导入多个文件。只需选择多个 文件即可。但请只使用系统的默认文件管理器，因为第三方文件 管理器并不总是支持多选。某些情况下必须先启用 “显示内部存储”选项。

可以使用备份功能对所有转储和密钥文件进行完整备份。 数据将保存为 ZIP 压缩包。

7.8 转换数据

此工具可以在不同格式之间转换数据（字节）。目前 支持以下数据类型。
  • ASCII
  • 十六进制
  • 二进制

7.9 UID 记录

此工具显示已发现标签的记录。每条记录由 日期、时间和所发现标签的 UID 组成。记录文件可以被清空 或分享给其他应用。

8. 外部 NFC

MCT 可以与 External NFC 配合使用。该应用允许您将基于 USB 的外部 RFID 读卡器连接到 您的设备。并非所有 RFID 读卡器都被 External NFC 支持，且您的设备必须支持 USB-OTG。

应该可以使用的读卡器：
  • ACR 122U
  • 通过 USB-UART 适配器连接的 MFRC522
  • 通过 USB-UART 适配器连接的 PN532
